# v2 리디자인 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 블로그를 zerolog(https://zerolog.vercel.app) 스타일의 초미니멀 구조로 재구성 — 홈 + Resume 두 라우트, 블랙 배경 모노크롬, Overused Grotesk 폰트.

**Architecture:** 기존 FSD 구조 유지. 공용 헤더 요소(Logo, SiteNav, SocialLinks)는 `src/shared/ui`에, 페이지별 코드는 `src/pages/home`, `src/pages/resume` 슬라이스에 둔다. feed/projects/me 슬라이스와 라우트는 전부 삭제하고 커리어 데이터는 `src/pages/resume/model/resumeData.ts`로 이전한다.

**Tech Stack:** Next.js 16 (App Router, Turbopack), React 19, Tailwind CSS 4, motion(framer-motion), TypeScript 5, pnpm.

## Global Constraints

- 스펙: `docs/superpowers/specs/2026-07-19-v2-redesign-design.md`
- 배경색 `#131313` 유지, 텍스트는 white/neutral 계열만. 컬러 악센트 금지, 링크는 underline만
- 폰트: Overused Grotesk(`--font-sans`), JetBrains Mono(`--font-mono`, 보조)
- 사이트명/로고 텍스트: `@leechan`
- 이 프로젝트에는 유닛 테스트 인프라가 없다. 각 태스크의 검증은 `pnpm build` + `pnpm lint` + 브라우저 확인으로 한다
- import는 `@/*` 별칭 사용 (`src/` 매핑), 클래스 결합은 `cn()`(`@/shared/lib/utils`) 사용
- 커밋은 `git commit --no-verify` 없이 훅 통과가 원칙. Conventional Commits 형식

```tsx
'use client';

import type { ReactNode } from 'react';
import { motion } from 'motion/react';

type Props = {
  children: ReactNode;
  className?: string;
};

/** Subtle fade + rise as the entry scrolls into view. */
export function Reveal({ children, className }: Props) {
  return (
    <motion.div
      className={className}
      initial={{ opacity: 0, y: 12 }}
      whileInView={{ opacity: 1, y: 0 }}
      viewport={{ once: true, margin: '-60px' }}
      transition={{ duration: 0.4, ease: 'easeOut' }}
    >
      {children}
    </motion.div>
  );
}
```
