### Introduce

자사 스테이블 코인 홈페이지는 React 기반 CSR 환경에서 동작하며, 검색엔진 인덱싱이 원활하지 않고 초기 로딩 속도가 느린 구조였습니다.
특히 이미지·폰트·비디오와 같은 대용량 리소스 최적화가 부족해 LCP 지표가 낮아지고, SEO 측면에서도 검색 노출에 제약이 있었습니다.
또한 Jenkins + scp 기반의 수동 배포 방식은 배포 효율성과 안정성을 보장하기 어려워 운영 부담이 컸습니다.

이러한 문제를 개선하기 위해 SEO 성능 강화와 운영 효율성 제고를 목표로 프로젝트를 Next.js 기반으로 마이그레이션했습니다.
SSR을 적용해 검색엔진 인덱싱 성능을 높이고, next/image 최적화 및 폰트·비디오 리소스 로딩 우선순위 조정을 통해 지표를 향상시켰습니다.
기존 수동 배포 방식을 EC2 + Nginx + PM2 기반의 GitHub Actions CI/CD 자동 배포 파이프라인으로 전환해 무중단 배포와 안정적인 운영 체계를 마련했습니다.

### Experience

- React 기반 웹 서비스를 Next.js로 마이그레이션, FSD 아키텍처 적용
- SEO 성능 향상을 위해 메타데이터 최적화, 자동 사이트맵, robots.txt 설정을 적용
- SSR 기반 next/image 최적화와 폰트·비디오 preload 적용으로 FCP 87%, LCP 69% 단축
- 기존 수동 배포를 AWS EC2·Nginx·PM2 기반 GitHub Actions CI/CD 파이프라인으로 전환, 무중단 배포 및 운영 안정성 확보, Next.js standalone 빌드로 배포 산출물 크기 최적화
- useMemo·useCallback·React.memo 적용으로 리렌더링 최소화, Emotion SSR 최적화로 초기 렌더링 시 스타일 안정성 강화
- 정적 콘텐츠는 SSR, 상호작용 컴포넌트만 CSR로 유지하는 하이브리드 전략 적용, 불필요한 코드 제거로 클라이언트 번들 사이즈 10% 감소
