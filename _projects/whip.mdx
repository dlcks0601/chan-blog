### Introduce

프로젝트를 시작할 때부터 협업 효율성과 코드 일관성을 최우선 과제로 삼았습니다. 이를 위해 AI 도구와 Cursor rule에 컨벤셔널 커밋 규칙을 적용해
팀원들과 일관성 있는 커밋 메시지를 작성하고, swagger-typescript-api와 같은 스웨거 제너레이터를 도입하여 API 호출 함수 및 타입 정의를 자동화했습니다.
또한 컴파운드 컴포넌트 패턴을 적용해 재사용성과 확장성을 높였으며, FSD 아키텍처를 도입해 도메인, 기능 단위로 구조화함으로써
역할 분담과 유지보수성을 강화하는 등 전반적인 DX를 개선했습니다.

또한 앱 부트스트랩 단계에서 API 데이터를 미리 preload하여 초기 화면 진h입 속도를 단축하고, FlashList와 useMemo를 적용해
대규모 리스트 렌더링 성능을 최적화하는 등 사용자가 체감하는 로딩 지연과 화면 끊김을 최소화해 UX를 개선했습니다.

### Problem & Solve

1. NFT 카드

#### 카드 플립 애니메이션 민감도 문제

Problem

- 초기 구현에서 카드 플립이 너무 둔감하게 반응
- 사용자의 미세한 드래그 동작을 제대로 감지하지 못함

Solve

- `useSharedValue`와 `withSpring` 애니메이션을 활용한 부드러운 반응성 구현
- 실시간 터치 추적을 위한 `REAL_TIME_TRACKING` 기능 추가

2. 손가락 움직임 추적의 부자연스러움

Problem

- 카드가 손가락 움직임을 즉시 따라가면서 어색한 애니메이션 발생
- 자연스러운 느낌이 부족

Solve

- 보간 기법을 활용한 애니메이션 적용
- Spring Physics 기반 움직임으로 현실감 있는 터치 반응 구현

```typescript
  // 터치 제스처 최적화
  TAP_THRESHOLD: 8,
  TAP_VELOCITY_THRESHOLD: 25,
  DRAG_SENSITIVITY: 2.0,

  // 제스처 충돌 해결
  panGesture.onStart(() => {
    gestureActive.value = true;    // 제스처 상태 명확화
  })
  .onUpdate((event) => {
    const dragDistance = isDirectionX ? event.translationY : event.translationX;
    const dragRotation = dragDistance * DRAG_SENSITIVITY;
    rotation.value = smoothInterpolation(dragRotation);
  })
```

- Gesture Handler의 터치 이벤트 생명주기 활용
- 제스처 간 우선순위 설정으로 충돌 방지
