### Introduce

프로젝트를 시작할 때부터 협업 효율성과 코드 일관성을 최우선 과제로 삼았습니다. 이를 위해 AI 도구와 Cursor rule에 컨벤셔널 커밋 규칙을 적용해
팀원들과 일관성 있는 커밋 메시지를 작성하고, swagger-typescript-api와 같은 스웨거 제너레이터를 도입하여 API 호출 함수 및 타입 정의를 자동화했습니다.
또한 컴파운드 컴포넌트 패턴을 적용해 재사용성과 확장성을 높였으며, FSD 아키텍처를 도입해 도메인, 기능 단위로 구조화함으로써
역할 분담과 유지보수성을 강화하는 등 전반적인 DX를 개선했습니다.

또한 앱 부트스트랩 단계에서 API 데이터를 미리 preload하여 초기 화면 진h입 속도를 단축하고, FlashList와 useMemo를 적용해
대규모 리스트 렌더링 성능을 최적화하는 등 사용자가 체감하는 로딩 지연과 화면 끊김을 최소화해 UX를 개선했습니다.

### Experience

- Expo 기반 FSD 아키텍처 설계 및 적용으로 도메인, 기능 단위 구조화, 협업 및 유지보수성 강화
- AI 도구 및 Cursor rule 기반 컨벤셔널 커밋 룰 도입으로 팀 코드 일관성 확보
- swagger-typescript-api 기반 Code Generation 도입으로 API 명세 자동화 및 DX 향상
- 앱 부트스트랩 단계에서 API 프리로드 및 Lottie 스플래시 스크린 적용으로 안정적이고 자연스러운 앱 시작 경험 제공
- FlashList와 useMemo, Lazy Loading을 적용해 대규모 리스트 렌더링 성능을 최적화하고 UX를 개선
- Web3Auth를 활용한 Google OAuth2 인증 구현
- i18n 기반 다국어 지원 (한국어, 중국어, 일본어)
- React Native Reanimated 기반 인터랙티브 NFT 카드 구현
- FCM(Firebase Cloud Messaging) 기반 푸시 알림 기능 구현
- Expo EAS를 활용한 빌드
